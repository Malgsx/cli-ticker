# Contributing

CLI is intended to be easy to fork and customize.

## Local Setup

```sh
git clone https://github.com/Malgsx/cli-ticker.git
cd cli-ticker
make run
```

Requirements:

- macOS
- Xcode Command Line Tools
- Python 3 with Pillow for regenerating icon assets

## Development Notes

- The working app is the Objective-C/AppKit target in `Sources/CLITickerObjC/main.m`.
- `InventoryService` owns local package-manager scanning.
- `MenuController` owns the menu bar UI and launch/report actions.
- Logos live in `Assets/Logos`.
- App/menu icons are generated by `scripts/generate_icon_assets.py`.

## Pull Requests

Good first improvements:

- Add support for more package managers.
- Add more agent-tool aliases and icons.
- Improve report formatting.
- Add signed/notarized release automation.
- Add opt-in remote release feeds.

Please keep scanning behavior privacy-preserving and local-first by default.
